# BuyMax – Max Buy Price & Risk Checker for Amazon Sellers

**BuyMax** is a Chrome extension for online-arbitrage sellers. On any Amazon product page it instantly answers the one question that matters before you buy: **"What's the most I can pay for this and still hit my target ROI?"** — plus a risk sensor that warns about brands frequently subject to authenticity investigations or manufacturer resale restrictions.

Amazon商品ページを開くだけで「**いくらまでなら仕入れてよいか**」を1秒で逆算し、真贋調査多発ブランド・転売規制メーカーを購入前に警告するChrome拡張です。
